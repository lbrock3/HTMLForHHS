How to Play

Using Gustar

Gustar requires indirect object pronouns and changes form based on what is being liked:

  • Use gusta for singular things and infinitives
  • Use gustan for plural things

Examples:

  • Me gusta el libro (I like the book)
  • Te gustan los libros (You like the books)
  • Le gusta estudiar (He/She likes to study)
