How to Play

Present Progressive

The present progressive tense describes actions that are currently happening.

It is formed with estar + present participle (-ando/-iendo)

Formation Rules

  • -AR verbs: remove -ar, add -ando
  • -ER/-IR verbs: remove -er/-ir, add -iendo
  • Special cases: some verbs change stems or use -yendo

Example: yo + hablar = estoy hablando
